# Beilai Terminology Library

A lightweight single-page terminology repository for Beilai.

## How to add terms

Only edit `terms.js`.

Add one object in this format:

```js
{
  cn: "中文术语",
  en: "English Term",
  note: "备注说明"
}
```

Example:

```js
{
  cn: "串口服务器",
  en: "Serial Device Server",
  note: "用于产品分类或功能描述。"
}
```
